# purdue-study-spot-finder

## Project Goal
Purdue Study Spot Finder is a Java program designed to help Purdue students find study locations that match their preferences. Students can browse campus study spaces and filter them based on noise level and study environment.

## MVP Scope
The initial version will include:
- A collection of Purdue study locations stored in a CSV file.
- The ability to view all available study locations.
- Filtering by noise level.
- Filtering by individual or group study environment.
- Displaying matching locations and their details.

## Future Plans
Potential future features include:
- Filtering by available outlets and seating.
- Displaying opening hours.
- Saving favorite study locations.
- Adding student-submitted reviews and ratings.

## Tech Stack
- **Language:** Java
- **Data Storage:** CSV file
- **Data Structures:** ArrayList
- **Development Environment:** VS Code
- **Version Control:** Git and GitHub
